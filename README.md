# ♡﹒seiunsecret

**seiunsecret** is a Hrmnx Entertainment-affiliated archive and promotional website dedicated to authorized unreleased works, demos, behind-the-scenes materials, and other selected content connected to seiun. Designed to feel like exploring a personal computer, the site brings together music, news, project files, and other materials in one interactive digital space.

Rather than presenting everything as a conventional website, seiunsecret takes inspiration from desktop operating systems, file explorers, and early internet aesthetics. Its interface combines a light cybercore atmosphere with soft silver and blue-gray tones, subtle animations, and angelic visual elements.

The idea is simple: give selected materials a place to live, make them easy to explore, and keep access to them within the intended community.

---

## ╰﹢about the project

seiunsecret was created as a companion archive for the SEIUN project under the Hrmnx Entertainment umbrella.

Some creative work takes time before it is ready for an official release. Demos, unfinished ideas, project updates, and other materials can still be meaningful along the way, even when they aren't intended for public distribution.

seiunsecret provides a dedicated space for sharing and organizing those materials when permission has been granted. It also serves as a place for promotional content and updates that help the community stay connected with the project.

The website is designed to feel less like browsing a database and more like opening someone's desktop: folders to explore, documents to read, and windows to move around as you discover what's inside.

## ╰﹢features

### ◜desktop-inspired interface﹒

- A desktop environment inspired by macOS and classic file explorers.
- Interactive windows for viewing documents and browsing archive sections.
- A dock for quick navigation between connected Hrmnx Entertainment websites.
- A desktop clock and familiar file and folder elements.
- Draggable windows and translucent interface elements.
- Responsive layouts intended to make the experience usable on different screen sizes.

### ◜archive and file explorer﹒

The archive is organized into dedicated sections, making it easier to separate different types of material.

| Section | Purpose |
| --- | --- |
| `members` | Member-related information and materials approved for the archive. |
| `news` | Updates, announcements, and relevant project news. |
| `nemawashi` | Selected materials and information connected to Nemawashi. |
| `music` | Authorized demos, music-related materials, and promotional content. |
| `website` | Website-related files, updates, and other approved materials. |

The archive structure is designed to grow as the project develops. New folders and categories can be added when there is a genuine need for them.

### ◜desktop documents﹒

The desktop can include several text-based documents that act as quick entry points to important information.

- `about.txt` — An introduction to seiunsecret and its purpose.
- `permissions.txt` — Information about access, permitted use, and content-sharing expectations.
- `discord.link` — A shortcut to the relevant Discord community or server.
- `music.txt` — Music-related information and notes.

These documents help keep important information accessible without making the main interface feel crowded.

### ◜sound and atmosphere﹒

Audio and small interface details are part of the experience, rather than an afterthought.

- Optional interface sound effects.
- A sound toggle so visitors can choose whether they want audio.
- Background audio with a looping playback option and fade effects.
- Subtle animations that give the desktop a little more life.
- Small decorative details, including pixel-style bunnies.

Sound should remain optional, allowing visitors to explore the archive without unexpected audio.

### ◜visual identity﹒

The visual direction of seiunsecret is built around a combination of:

- Light cybercore and digital archive aesthetics.
- Silver, muted blue-gray, and soft neutral tones.
- Angelic and celestial-inspired imagery.
- The Inter typeface.
- Translucent windows, understated borders, and layered interface elements.
- Small animated details that give the site personality without overwhelming the content.

The goal is to make the site feel personal, slightly mysterious, and connected to the identity of seiun.

### ◜connected hrmnx entertainment services﹒

The desktop dock can link to other websites in the Hrmnx Entertainment ecosystem, including:

## ╰﹢content and permissions

Because seiunsecret may contain unreleased creative material, permissions are an important part of the project.

**Not everything in the archive is intended for public release.** Content should only be uploaded, displayed, or shared when the appropriate authorization has been obtained.

The site distinguishes between two important categories:

**teasers**

Demos and other authorized previews of unreleased work are treated as teasers. Their purpose is to provide a limited preview, not to imply that the material has been officially released.

**promotion**

Other approved materials may be categorized as promotion. This can include announcements, selected project information, behind-the-scenes content, and other materials intended to support the seiun project.

### ◜general guidelines﹒

- Only include materials that are authorized for the intended audience.
- Respect any restrictions attached to unreleased music, demos, images, documents, and other creative work.
- Do not assume that access to a file grants permission to redistribute it.
- Keep promotional content separate from material that is only approved for limited access.
- Update archive contents when permissions or release plans change.
- Avoid publishing private information, credentials, or confidential material that does not belong on the website.

These guidelines help keep the archive useful without compromising the people or projects behind it.

## ╰﹢privacy and security

The contents of an archive can be sensitive even when the website itself looks like a simple frontend.

A few important considerations:

- Do not commit passwords, API secrets, private tokens, or other credentials.
- Avoid including private personal information in publicly accessible files.
- Remember that hiding a folder or removing a link from the interface does not secure its contents.
- Do not treat client-side JavaScript checks as reliable access control.
- If certain files must remain private, store them behind appropriate server-side or storage-level permissions.
- Review repository visibility and deployment settings before adding unreleased material.
- Use placeholder values for configuration examples in documentation.

**Important:** A website's appearance does not determine who can access its files. If a particular demo, document, or other asset must only be available to selected people, its actual storage and delivery permissions need to enforce that restriction.
